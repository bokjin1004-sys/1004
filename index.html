홍보영상 편집

여기서 수정한 내용은 이 브라우저에 자동 저장되어, 다음에 이 파일을 열어도 그대로 남아있어요.
사진은 "파일 선택"으로 올리거나, 인터넷에 있는 이미지라면 "이미지 주소"만 입력해도 됩니다.
각 카드의 ↑↓ 버튼으로 전체 재생 순서를 자유롭게 바꿀 수 있어요 (인트로·서비스·연락처 화면도 포함). 인트로·서비스·연락처 화면은 각자 배경색이나 배경 사진도 따로 지정할 수 있어요.
문구 글씨 (이미지가 없을 때)
이미지 크기 (이미지를 사용할 때)
저장소 정보는 이 프로젝트 것으로 이미 채워져 있어요. 페이지를 여는 모든 사람은 토큰 없이도 자동으로 최신 내용을 불러와요. 사진/문구를 바꿔서 모두에게 반영하고 싶을 때만 아래 Personal Access Token을 입력하고 "GitHub에 저장"을 누르세요. 토큰은 이 브라우저에만 저장되고, 내보내기 파일에는 포함되지 않아요.
토큰 만드는 법: GitHub 접속 → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access는 이 저장소 하나만 선택하고, Permissions → Contents를 Read and write로만 켜서 만드세요.

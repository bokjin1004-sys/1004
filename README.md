# 1004보금자리 홍보 슬라이드쇼

사진이 풀스크린으로 나오고, 제목/설명이 계속 바뀌는 히어로 슬라이드쇼 웹페이지입니다.
브라우저에서 바로 사진과 문구를 편집할 수 있는 편집 화면이 내장되어 있고,
**GitHub에 저장하면 별도 배포 작업 없이 누구나 접속할 때 최신 내용이 자동으로 보입니다.**

## 구성

- `index.html` : 슬라이드쇼 재생 화면 + 편집 화면이 모두 들어있는 단일 페이지
- `data/content.json` : 실제로 배포되는 슬라이드/문구 내용 (사진, 제목, 순서 등)
- `.github/workflows/pages.yml` : 기본 브랜치(현재 `claude/determined-meitner-vwgjgh`)에 push하면 자동으로 GitHub Pages에 `index.html`을 배포

빌드 과정이 없는 순수 정적 페이지입니다.

## 동작 방식

- 페이지를 열면 `https://raw.githubusercontent.com/bokjin1004-sys/1004/<브랜치>/data/content.json`을
  **토큰 없이** 자동으로 불러와서 화면에 보여줍니다. 이 저장소 정보는 편집 화면에 이미 기본값으로
  채워져 있어서, 별도 설정 없이 **누구나 페이지를 열기만 하면 최신 내용을 보게** 됩니다.
- 화면 오른쪽 위 **"✎ 사진 편집"** 버튼을 누르면 편집 화면이 열립니다. 여기서 고친 내용은
  일단 이 브라우저에 자동 저장(localStorage)되지만, **다른 사람에게 보여주려면 반드시
  "GitHub에 저장" 버튼으로 실제 GitHub 저장소에 커밋해야 합니다.**

## 사진/문구를 추가해서 실제로 반영하는 방법 (추천 방법)

1. 페이지에서 **"✎ 사진 편집"** → **"☁️ GitHub 연동"** 칸으로 이동합니다.
   저장소/파일 경로/브랜치는 이미 이 프로젝트 값으로 채워져 있으니 그대로 두면 됩니다.
2. **Personal Access Token**을 처음 한 번만 발급해서 입력합니다 (이후에는 이 브라우저에 계속 저장되어 있어요).
   - GitHub 접속 → 오른쪽 위 프로필 → Settings → 맨 아래 **Developer settings** →
     **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
   - **Repository access**는 이 저장소(`1004`) 하나만 선택
   - **Permissions → Contents**를 **Read and write**로만 설정 (다른 권한은 켤 필요 없음)
3. 사진(파일 선택 또는 이미지 URL), 제목, 순서 등을 원하는 대로 편집합니다.
   - 파일로 올린 사진은 자동으로 가로/세로 최대 1920px, JPEG 82% 품질로 줄여서 저장하므로
     스마트폰 원본 사진을 그대로 여러 장 올려도 파일이 과도하게 커지지 않습니다.
4. **"☁️ GitHub에 저장"**을 클릭합니다. 그러면 즉시 저장소의 `data/content.json`에 커밋되고,
   보통 몇 분 안에(브라우저 캐시에 따라 다름) 이 페이지를 여는 모든 사람에게 반영됩니다.
   - **"↻ GitHub에서 지금 불러오기"**로 저장된 내용을 다시 불러와 이어서 편집할 수도 있습니다.

> 저장할 때 브라우저는 GitHub Contents API로 파일을 커밋하고, 그 커밋이 push되면
> `.github/workflows/pages.yml`이 자동으로 GitHub Pages도 다시 배포합니다
> (저장소의 **Actions** 탭에서 진행 상황을 볼 수 있습니다). 페이지 자체는 raw 파일을
> 직접 불러오기 때문에, Pages 재배포를 기다리지 않아도 곧 새 내용이 보입니다.

### 참고: 파일로 직접 백업/복원하기

편집 화면의 **"내보내기 (백업 파일)"** / **"가져오기 (백업 파일)"** 버튼으로 전체 내용을
JSON 파일로 내려받거나 다시 불러올 수 있습니다. GitHub 연동 없이 수동으로 백업해두고 싶을 때 사용하세요.

## 화면보호기/절전모드 때문에 화면이 꺼지는 경우

모니터에 상시 재생용으로 연결해두었는데 몇 분 뒤 화면보호기나 절전모드로 꺼진다면:

- 이 페이지는 **Wake Lock API**를 사용해서, 지원하는 브라우저(최신 Chrome, Edge 등)에서는
  페이지가 열려 있는 동안 화면이 꺼지지 않도록 자동으로 요청합니다. 추가 설정 없이 동작합니다.
- 다만 Wake Lock은 **브라우저 탭이 보이는 상태(포그라운드)일 때만** 유지되고, 일부 OS의
  자체 화면보호기 프로그램이나 모니터 자체의 절전 설정까지는 막지 못할 수 있습니다.
  화면이 계속 꺼진다면 다음도 함께 확인해주세요.
  - **Windows**: 설정 → 시스템 → 전원 및 배터리 → 화면 및 절전에서 "화면 끄기"를 "안 함"으로 변경,
    설정 → 개인 설정 → 잠금 화면 → 화면 보호기에서 화면 보호기를 "(없음)"으로 변경
  - **macOS**: 시스템 설정 → 잠금 화면에서 "다음 시간 동안 사용하지 않으면 화면 끄기"를 "안 함"으로 변경
  - 브라우저를 **전체 화면(F11)** 으로 띄우고, 그 탭이 계속 활성 탭(포그라운드)에 있도록 두세요.

## GitHub Pages 처음 설정하기

1. GitHub 저장소의 **Settings → Pages**로 이동합니다.
2. **Source**를 `GitHub Actions`로 선택합니다. (한 번만 설정하면 됩니다)
3. 기본 브랜치에 push하면 `https://bokjin1004-sys.github.io/1004/` 주소로 자동 배포됩니다.

## 그 밖의 기능

- 화면 하단의 재생/일시정지 버튼, "다음" 버튼으로 슬라이드를 직접 넘겨볼 수 있습니다.
- 화면을 클릭해도 재생/일시정지가 토글됩니다.
- 상시 재생 화면을 깔끔하게 보여주기 위해, 컨트롤 버튼들은 마우스를 움직이거나 화면을 클릭할 때만
  잠깐 나타났다가 3초 후 자동으로 사라집니다.
- 편집 화면의 **"🎬 영상 다운로드"** 버튼으로 슬라이드쇼를 mp4/webm 영상 파일로 내려받을 수 있습니다.
  (최신 Chrome 브라우저 권장. 외부 URL 사진 중 일부는 브라우저 보안 정책상 영상에 포함되지
  않을 수 있으니, 영상으로 내보낼 사진은 "파일 선택"으로 직접 올리는 것을 권장합니다.)

## 로컬에서 미리보기

간단한 로컬 서버로 열어보면 됩니다.

```bash
python3 -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000` 접속.
